## Short description

เดโม Stealth-Puzzle Platformer 3 ด่านในโรงเรียนไทย หลบครู ใช้เสียงแก้ปริศนา และหนีให้ทันก่อนหมดเวลา!

## Description

รับบทเป็น “น็อต” นักเรียนที่ตัดสินใจหนีออกจากคาบเรียน ผ่านทางเดิน โรงอาหาร และห้องสมุดภายในเวลา 3–5 นาที หลบมุมมองครูและ CCTV ซ่อนตัว ใช้ไอเท็ม และเลือกข้ออ้างให้ถูกก่อนถึงทางออก

### Controls

- A/D or Arrow keys: Move
- Shift: Run (fast but noisy)
- Space: Jump / Double Jump (press twice); also exits a hide spot
- S / Down: Crouch and reduce visibility
- E: Interact / enter or exit a hide spot
- Q: Use selected item
- 1–3: Select inventory slot
- Esc: Pause
- Mobile: Landscape touch controls are included
